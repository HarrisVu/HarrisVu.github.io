# Harris Vu — academic website

Static academic website for Harris Vu, Research Fellow at AUT Center for Financial Research, Auckland University of Technology, New Zealand.

## Files

- index.html: biography, research, publications, working papers, projects, teaching, industry engagement and professional links.
- styles.css: colours, typography and responsive layout.
- script.js: navigation and publication filters; all content remains readable without JavaScript.
- assets/harris-vu.jpg: supplied 1024×1024 portrait, used without AI alteration.
- assets/favicon.svg: HV monogram.
- .nojekyll: serves these static files directly through GitHub Pages.

No dependencies or build step are required. Open index.html locally, or serve this folder with python -m http.server 8000.

## Editing

Edit the text and verified links in index.html. Keep published articles, working-paper statuses and research-proposal acceptances distinct. Update dates when content changes. The historical Vietnam engagement dates indicate starting years.

## Hosting

For the personal GitHub Pages site, serve the main branch root in the HarrisVu.github.io repository. Local asset links are relative. No analytics, cookies, third-party scripts or forms are used.
